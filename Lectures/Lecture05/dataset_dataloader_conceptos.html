Dataset y DataLoader

Qué hace cada componente, cómo se conectan internamente y qué ocurre realmente cuando escribimos for x, y in loader.

Idea central

Dataset define ejemplos; DataLoader organiza cómo llegan al modelo

Sampler
→
Dataset
→
collate_fn
→
Batch
→
Modelo
Dataset: “¿Qué ejemplo corresponde al índice i?”
DataLoader: “¿Cómo selecciono, cargo y agrupo esos ejemplos?”
1 · Dataset

Índice → ejemplo

i → (xi, yi)

Un Dataset típico implementa dos operaciones esenciales:

len(dataset)      # __len__()
dataset[i]        # __getitem__(i)

Por ejemplo:

class MyDataset(Dataset):
    def __init__(self, X, y):
        self.X = X
        self.y = y

    def __len__(self):
        return len(self.y)

    def __getitem__(self, idx):
        return self.X[idx], self.y[idx]
El Dataset devuelve un ejemplo, no un batch.
2 · DataLoader

Ejemplos → batches

Con batch_size=4, el DataLoader hace conceptualmente:

indices = [0, 1, 2, ..., N-1]

for start in range(0, N, 4):
    batch_indices = indices[start:start+4]

    samples = [
        dataset[i]
        for i in batch_indices
    ]

    batch = collate(samples)
    yield batch

PyTorch implementa esto de forma más sofisticada, pero este es el modelo mental correcto.

3 · shuffle

El Dataset no se desordena

dataset[27] sigue significando “dame el ejemplo 27”. Lo que cambia es el orden de los índices.

shuffle=False 0, 1, 2, 3, 4, 5, 6, ... shuffle=True 481, 7, 1920, 43, 991, ...

Conceptualmente, esa responsabilidad pertenece al Sampler.

4 · Sampler

¿Qué índices visitar?

El Sampler produce índices, no datos.

SequentialSampler 0, 1, 2, 3, 4, ... RandomSampler 42, 7, 91, 3, 15, ... WeightedRandomSampler índices con probabilidades distintas

Esto permite estrategias como sobremuestreo de clases raras o sampling personalizado.

5 · BatchSampler

Índices → grupos de índices

Si el Sampler produce:

17, 3, 94, 21, 8, 51, 10, 74, ...

con batch_size=4, el BatchSampler forma:

[17, 3, 94, 21] [8, 51, 10, 74] ...
6 · __getitem__

Los índices se convierten en ejemplos

dataset[17]
dataset[3]
dataset[94]
dataset[21]

Si cada llamada devuelve (image, label), todavía tenemos cuatro ejemplos individuales. Falta agruparlos.

7 · collate_fn

Lista de ejemplos → batch de tensores

Cada imagen:

[3, 32, 32] [3, 32, 32] [3, 32, 32] [3, 32, 32]

Después de collate_fn:

[4, 3, 32, 32]

Las etiquetas pasan de escalares a:

tensor([3, 7, 1, 4])
Batch de imágenes = [B, C, H, W]

9 · drop_last

¿Qué pasa con el último batch?

Si tenemos 10 ejemplos y batch_size=4:

drop_last=False 4 + 4 + 2 drop_last=True 4 + 4

El batch incompleto se descarta solo cuando drop_last=True.

10 · workers

Paralelizar la carga

Con num_workers=0, el proceso principal carga los datos.

Con varios workers:

DataLoader ├── worker 1 → dataset[i] ├── worker 2 → dataset[j] ├── worker 3 → dataset[k] └── worker 4 → dataset[m]

Es útil cuando abrir archivos o aplicar transformaciones cuesta tiempo.

11 · pin_memory

CPU → GPU

pin_memory=True puede ayudar a hacer más eficiente la transferencia de batches desde CPU hacia GPU.

images = images.to(
    device,
    non_blocking=True
)

No modifica el contenido de los datos; es una optimización del pipeline.

12 · transforms

¿Dónde ocurre el preprocessing?

def __getitem__(self, idx):
    image = load_image(idx)

    if self.transform:
        image = self.transform(image)

    return image, label
Las transformaciones normalmente ocurren dentro del Dataset cuando el DataLoader solicita un ejemplo.
13 · Train / Validation / Test

Las responsabilidades cambian según la partición

Train
  • augmentation
  • shuffle=True
  • optimización del modelo
Validation / Test
  • sin augmentations aleatorias
  • shuffle=False
  • evaluación reproducible
14 · Estratificación

Preservar proporciones de clase

En clasificación, una partición estratificada intenta conservar las proporciones de las etiquetas.

train_idx, val_idx = train_test_split(
    indices,
    test_size=0.2,
    random_state=42,
    stratify=labels
)

Después podemos crear Subset o vistas del mismo dataset con transforms diferentes.

15 · Entrenamiento

Lo que oculta el `for`

for images, labels in train_loader:
    predictions = model(images)
    loss = criterion(predictions, labels)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

La primera línea oculta todo el pipeline de sampling, carga y batching.
