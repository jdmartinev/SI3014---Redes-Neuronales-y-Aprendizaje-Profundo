# Competition 4

This competition is divided into **two stages**:

## Stage 1: Text Classification (Yale Dataset)
Participants must build a model to perform **text classification** using the Yale dataset.  
This stage focuses on preprocessing, feature extraction, and model training.

📅 **Deadline:** April 30th 
You must submit the **first part (classification task)** within the established deadline.

---

## Stage 2: Text Generation
In the second stage, participants will work on **text generation**, applying language models to produce coherent and context-aware outputs.

More details about this stage will be provided after the first submission.

---
## Deliverables (Stage 1)
- Executed notebook
- Clear description of preprocessing and model
- Evaluation metrics
- Markdown document with **AI usage declaration**
- Markdown document describing the **selected architecture**

---

Make sure your submission is complete and reproducible.
